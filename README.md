# Weather UI

A weather dashboard interface mockup built with **HTML, CSS and JavaScript**.

## Features
- Weather card layout.
- Temperature and condition display.
- Responsive styling.

## Important note
This is a front-end design demo. The displayed weather values are fictional sample data; the project does **not** fetch live weather information.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — dashboard structure
- `style.css` — dashboard styling
- `script.js` — interface behaviour

## What this project practises
Building a dashboard layout and presenting data in a user interface.
